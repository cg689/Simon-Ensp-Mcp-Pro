# 功能一：一键生成拓扑文件（.topo）

## 这个功能是干什么的？

华为 eNSP 里搭拓扑（拖设备、拉网线）很费时间。这个功能让你**只写几行文字描述**，自动生成 eNSP 能直接打开的 `.topo` 文件：

```
你写：R1、R2 两台路由器 + 一台交换机 SW1 + 两台 PC，按 xxx 连线
        ↓  运行脚本（1 秒）
得到：双击就能在 eNSP 打开的拓扑文件，设备和连线都画好了
```

**不需要安装 MCP，不需要启动 eNSP，任何装了 Python 的电脑都能跑。**

---

## 30 秒体验（零安装）

前置：电脑上有 Python 3.10+（没有就去 [python.org](https://www.python.org/downloads/) 装一个，安装时勾选 "Add to PATH"）。

在仓库根目录打开命令行（cmd 或 PowerShell），运行：

```bat
python "功能1-生成拓扑\一键体验.py"
```

看到 `ALL PASS` 后，当前目录会出现 **`体验拓扑.topo`**——双击它（或拖进 eNSP 窗口），能看到 3 台路由器 + 1 台交换机 + 2 台 PC 已经画好连线。这就是本功能做的事。

## 日常怎么用

### 方式 A：让 AI 帮你干（推荐）

把仓库里的 `skill/ensp-topo-generate/` 文件夹拷到你的 AI 助手技能目录：

| 你用的 AI 工具 | 拷到哪里 |
|---|---|
| WorkBuddy | `C:\Users\<你的用户名>\.workbuddy\skills\` |
| Claude Code | `C:\Users\<你的用户名>\.claude\skills\` |

然后对 AI 直接说：

```
帮我生成一个拓扑：
- 设备：AR2220×2（R1、R2）、S5700×1（SW1）、PC×2
- 连线：R1 GE0/0/0 ↔ SW1 GE0/0/1，R2 GE0/0/0 ↔ SW1 GE0/0/2，
       PC1 ↔ SW1 GE0/0/3，PC2 ↔ SW1 GE0/0/4
```

AI 会生成 `.topo` 并自检后给你。

### 方式 B：自己改脚本

1. 复制 [`模板脚本.py`](模板脚本.py)，改名如 `gen_我的实验.py`
2. 只改两个表格：
   - `D`（设备表）：`("设备名", "型号", Telnet端口, x坐标, y坐标)`
   - `L`（连线表）：`("设备A", 接口A, "设备B", 接口B, "备注")`
3. 运行 `python gen_我的实验.py`，看到 4 行 ALL PASS 就成了

**你只需要写接口名**（如 `GE0/0/1`），脚本里的 helper 函数（`ar_ge(1)`、`s5700_ge(1)`……）会自动换算成 eNSP 内部编号——手算编号是最容易出错的地方，别自己算。

完整示范（双出口 + 双防火墙，11 台设备 14 条线）见 [`示例-双出口.py`](示例-双出口.py)，生成结果见 [`示例-双出口.topo`](示例-双出口.topo)。

## 支持哪些设备型号？

AR1220 / AR2220 / AR2240、S2700 / S3700 / S5700 / S6700、AC6005、AP6050、USG5500、**USG6000V（本仓库补丁新增，上游没有）**、PC / STA（无线终端）/ Laptop / Server。

## 常见问题

| 现象 | 原因与解决 |
|---|---|
| eNSP 打开后中文设备名乱码 | 你自己写的落盘代码用了 UTF-8。**必须 GBK 编码写盘**，照抄模板脚本末尾的落盘三段 |
| 报 `ModuleNotFoundError: grbj_ensp_mcp` | 没装包。零安装跑法：把仓库根的 `src` 加入 `sys.path`（一键体验.py 就是这么干的）；或按根 README「安装」一节装 wheel |
| 生成的拓扑里 USG6000V 打不开/缺端口 | 确认你用的是**本仓库**的 `src/topo_builder.py`（带补丁版），上游原版不支持 USG6000V |
| 想给设备加更多接口 | **不支持**。本工具只生成与 eNSP GUI 默认形态一致的设备（如 USG6000V = 1 管理口 + 7 业务口），改 XML 加口会导致文件异常 |
